Institution / Federated Access

{{ "Public identifiers entered; Save to apply changes." if settings_form.institution_name or settings_form.institution_idp_entity_id else "Not configured. Manual institutional access remains available." }}

Leave these blank if unknown. Use public identifiers only, never account details, passwords, tokens or session data. An IdP entity ID identifies your institution's identity provider; it is not a login link.

Configured institution ≠ authenticated session ≠ full-text entitlement. These settings do not prove IdP or service login, access to a Paper, or a saved Zotero PDF.

Automatic federated access is unavailable until a service route is verified. Use the Paper's service page or your manual Publisher Access URL; existing OpenAthens host associations remain independent.
