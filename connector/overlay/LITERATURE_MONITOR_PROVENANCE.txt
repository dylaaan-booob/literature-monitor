This artifact preserves the A1 source/license/build boundary and includes
the v0.6.1 A5 Literature Monitor automatic-capture delta: localhost bridge
runtime, dedicated DOI task-tab orchestration, pinned upstream translator save
integration, and attachment-independent top-level save observation.

Unreleased v0.6.3 A2 source delta adds invocation/session attribution,
one-shot live parent-dispatch permission, finite stale-command rejection,
and separate parent/PDF outcome reporting. PDF remains unverified because
this pinned source provides no established actual-PDF completion evidence.

Unreleased v0.6.3 A6 adds an AGPL Access Service policy overlay and bounded
main-frame navigation observation in the current DOI task tab. The production
verified-rule table is empty: no automatic federation route is enabled.
Session/authentication/entitlement observations remain unknown. Existing proxy
host associations and official native parent/PDF boundaries are preserved.

Unreleased v0.6.3 challenge/readiness correction binds automatic translation and
native dispatch to the selected top document, observes challenge responses/DOM,
and recovers pre-save navigation within the original preparation deadline.
Ordinary DOI same-origin progress is bounded separately from verified federation.
A challenged document cannot regain eligibility from unversioned DOM/translator
changes; new-document checks or safe manual fallback are required.

Paper Enrichment (SPEC §§47–48) adds a separate read-only content-script
message and MV3 offscreen Translate Framework handler. libraryID:false and
saveAttachments:false plus a loaded-translator browser-mode guard prevent
native/Server saving. The overlay shares Import/Preparation browser exclusion
and transports a transient candidate; only explicit Web Save writes missing Abstract/date fields.
No upstream pin, submodule revision or Manifest permission change is introduced.

The unified read-only handler uses pinned Zotero.Date.strToDate() in offscreen
and transports original date plus parsed components. Only the MIT server fills
missing month/day with compatibility 01s and validates the calendar date.
No date parser source crosses the AGPL/MIT boundary.

Paper Enrichment Authors (SPEC §50) forwards original creators from the same
read-only Item and advertises paper-enrichment/v2. Role/name interpretation and
explicit local Author/Paper writes are performed by the MIT server. No native
save, Manifest permission, upstream pin or submodule revision is changed.


Shibboleth Attribute Release Consent (SPEC §53) adds optional
shibboleth-consent/v1 capability and one command Boolean. The CARSI overlay
uses existing HTTPS/scripting/webNavigation permissions, existing login waiting
and current task authorization. It binds isolated-world native clicks to the
configured HTTPS IdP origin and current Portal document, once per document.
No credential, attribute payload, Cookie, authentication request construction,
login-state storage, native save or upstream/submodule pin change is introduced.
The MIT server owns the default-off Settings preference; IdP consent itself is
stored only by the school through its native form. Existing §48 date-padding
notes above are historical and were superseded by SPEC §§51–52.

Connector Lifecycle Cleanup adds patch 0004 after the Paper Enrichment delta.
It fixes tab-ID comparison, loading-tab liveness, actual cleanup results and
JSON diagnostics, and removes orphaned tab-info/injection caches. Candidate
snapshots protect records created during a cleanup query. Existing tab-close
listeners, periodic intervals, native Translator/parent/attachment saving and
read-only Enrichment remain unchanged. No tabs or offscreen documents are
closed; no persistent state, telemetry or measured memory-saving claim is added.
Upstream pins, submodule revisions and Manifest permissions remain unchanged.

Journal cover search development delta (SPEC §56): the separate AGPL cover overlay
recognizes regional Google pages and maps the first result's imgurl or embedded
result-ID/thumbnail/original record to its original URL. It parses page data without
executing it or requiring a preview click. URL recovery mechanisms were informed
by ViewImage (https://github.com/bijij/ViewImage) and Classic View for Google Images
(https://github.com/hsr88/classic-view-for-google-images); no dependency is bundled.
Chrome's extension background downloads originals using existing host permissions,
credentials=omit, normal redirects, a 20-second deadline and streaming 5 MiB limit.
Three searches run per group; download/submission is serial. Runtime advertises
journal-covers/v2 and submits Base64 bytes for MIT-side conversion and atomic saving,
with shared browser exclusion and 25-second result transport. Continue/Retry use
fresh request IDs over an in-memory current batch; Reset locally deletes cover
assets without starting a task. Navigation uses owned tabs and committed documents,
retaining user-navigated pages. No permission, browser dependency, Zotero save
authority, application version or upstream revision changes are introduced.

Background task window development delta (SPEC §61): runtime and CARSI overlays
create unfocused normal non-incognito task windows. Subsequent Import tabs and
verified CARSI Detail tabs are inactive. Detail navigation extracts the unique
exact Service result's official URL, rechecks its Portal Document and authority,
and owns the Tab ID returned by tabs.create instead of observing an anchor popup.
Official Visit observation and evidence are unchanged. Completion does not
focus/activate the application. The optional
background-task-windows/v1 claim metadata associates one Kept workflow/generation
with a transient window, without changing task/native-save authority. Import Only
retains an owned blank anchor until batch end and removes it only when its original
committed document and unchanged URL are verified. Preparation pages remain open;
Enrich/Import matching-document cleanup and native-save settlement are preserved.
No browser-state persistence, permission, version or upstream pin changes are added.
